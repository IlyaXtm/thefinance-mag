# TheFinance Mag — `claude-main` branch

Headless rebuild of `thefinance.ir/mag`: WordPress + WPGraphQL as the content
layer, Next.js App Router as the public frontend.

This branch is an **independent track**. It does not build on
`codex/phase0-foundation` and makes its own structural choices.

---

## Domain model

| Host | Role |
|---|---|
| `thefinance.ir/mag` | Public. Where articles live and all SEO equity accrues. |
| `wp.thefinance.ir` | CMS only — `/wp-admin`, `/graphql`, media. Fully de-indexed. |

Three rules follow from that split, and breaking any of them is silent:

1. Canonicals always point at `thefinance.ir/mag/<slug>`. Rank Math returns
   whatever `siteurl` is, so `siteurl` stays on the public host.
2. `wp.thefinance.ir` returns `X-Robots-Tag: noindex` on every path.
3. Sitemaps are generated by Next.js and list frontend URLs only.

## Current state

**Live.** `thefinance.ir/mag` is served by this app in production, as the
Docker container `thefinance-mag` on the shared host `thefinance-main`,
behind the CDN and that host's nginx. Releases are tagged `mag-prod-*`;
`/mag/health` reports the running build. How a release goes out:
`docs/infra/frontend-deploy.md` (reference) and `docs/learn/after-a-round.md`
(checklist).

**WordPress — the content layer.** `wp.thefinance.ir`, fully de-indexed,
WPGraphQL + `wp-graphql-rank-math`, and `wordpress/mu-plugins/` (`market`
taxonomy, `readingTime`, `marketDescription`, the redirect map, preview and
revalidation). About 110 published posts; an RSS automation adds news daily.

**Frontend — built.** Every route renders: home, article, archive, category
and education topics, news and news by market, author, search, feed and
sitemap. Components in `src/features/mag/components`, shared chrome in
`src/shared/ui`. Behaviour tests: `npm test`. Status and open items:
`docs/implementation-status.md` and `docs/backlog.md`.

**New here?** Start at `docs/learn/README.md`.

## Structure

```
CLAUDE.md                 project context and hard constraints
.claude/agents/           four subagents: frontend, seo, wordpress, reviewer
docs/                     decisions, findings, design summary
wordpress/mu-plugins/     deployed to wp.thefinance.ir
infra/wp/                 docker compose for the CMS VPS
infra/nginx/              nginx configs for the CMS VPS
src/features/mag/         feature module — see below
```

Flat, not a monorepo. One app, so `apps/web/` would add a level for nothing.
Follows the same convention as the other products: domain code in
`src/features/<feature>`, shared UI in `src/shared`, route-specific UI in
`_components`.

### Feature module

```
src/features/mag/
  types/       mag.types · mag-seo.types · mag-blocks.types
  api/v1/      mag.api (real) · mag.mock · mag.service (the switch)
  queries/     use-mag-*.swr — import only from the service
  lib/         seo · blocks
  components/
```

Rules that come with it:

- No `fetch()` in a page or component when a feature API exists
- No direct mock import outside `mag.service.ts`
- Switching mock ↔ real is `NEXT_PUBLIC_USE_MOCK`, never a refactor
- Server components read the service directly for indexable content; SWR hooks
  are for client-interactive views only. SWR hands crawlers an empty shell, and
  SEO is this product's first priority.

## Getting started

```bash
npm install
NEXT_PUBLIC_USE_MOCK=true npm run dev
```

The mock returns realistic Persian content with configurable latency
(`NEXT_PUBLIC_MOCK_LATENCY_MS`) and a forced failure mode
(`NEXT_PUBLIC_MOCK_FAIL=1`) so loading and error states are testable before any
real data exists.

Quality gates:

```bash
npx tsc --noEmit
npm run lint
npm test
npm run build
```

## Rollback, in one line

```bash
ssh thefinance-main 'sudo ~/deploy.sh --rollback'
```

`deploy.sh` keeps the previous container as `thefinance-mag-prev`, so going
back one release is a rename, seconds not minutes. Further back: every release
is tagged `mag-prod-*`, and `sudo ~/deploy.sh <sha>` redeploys any image still
on the host. The old WordPress theme was never deleted; the nginx switch to it
belongs to the main team.
