لینک شده — چه داخل همین پوشه، چه بیرون از آن.

> چرا همه‌چیز داخل `docs/learn` نیست؟ چند سند (قواعد پروژه، تصمیم‌ها، مرجع
> دیپلوی) از کد و از اسکریپت‌ها با همین مسیرها ارجاع داده شده‌اند. جابه‌جا
> کردنشان آن ارجاع‌ها را می‌شکند. برای همین سر جایشان مانده‌اند و از این‌جا
> لینک شده‌اند.

## در کد، از این فایل‌ها شروع کن

| فایل | چرا |
|---|---|
| `src/app/page.tsx` | صفحه‌ی اصلی — ببین صفحه چطور فقط چیدمان می‌کند |
| `src/features/mag/lib/landing.ts` | همان صفحه، از طرف منطق — کدام مطلب کجا |
| `src/features/mag/api/v1/mag.service.ts` | تنها نقطه‌ی انتخاب داده‌ی واقعی یا ساختگی |
| `src/middleware.ts` | ریدایرکت‌ها و ۴۰۴ — قبل از هر صفحه |
| `tests/lib.test.ts` | تست‌ها — بهترین توضیح از این‌که منطق قرار است چه کند |
| `infra/mag/deploy.sh` | دیپلوی — کامنت‌های بالای فایل را کامل بخوان |

## کامندهایی که هر روز لازم داری

```bash
npm run dev              # سرور توسعه (پورت 3000)
npx tsc --noEmit         # تایپ‌ها
npm run lint             # قواعد کد
npm test                 # تست‌های منطق
curl -s https://thefinance.ir/mag/health    # پروداکشن: کدام نسخه، از کدام داده
```
