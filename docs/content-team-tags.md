# برچسب‌ها و توضیحات صفحه‌ی آموزش — برای تیم محتوا

**تاریخ:** ۱۳ مهر ۱۴۰۵ (2026-10-05)

> فارسی است چون به تیم محتوا داده می‌شود، مثل `cta-unlinked.md`.

صفحه‌ی «آموزش بازارهای مالی» حالا چند بخش دارد که **فقط با برچسب (Tag) وردپرس
روشن می‌شوند**. تا وقتی مطلبی برچسب نخورد، آن بخش اصلاً نمایش داده نمی‌شود —
پس هیچ‌چیز خالی یا نیمه‌کاره روی سایت نمی‌ماند. بعد از برچسب‌زدن، حداکثر ۵
دقیقه طول می‌کشد تا روی سایت بیاید؛ نیازی به انتشار نسخه‌ی جدید سایت نیست.

## ۱. برچسب‌ها — دقیقاً با همین نامک (slug)

در **نوشته‌ها ← برچسب‌ها** بسازید. نامک مهم است، نه نام نمایشی:

| کاربرد | نام | نامک (slug) |
|---|---|---|
| راهنمای جامع — کارت بزرگ بالای صفحه‌ی آموزش | راهنمای جامع | `راهنمای-جامع` |
| چیپ «شروع از صفر» | شروع از صفر | `شروع-از-صفر` |
| چیپ «آپشن» | آپشن | `آپشن` |
| سطح آموزش، کنار نام دسته روی کارت | مقدماتی | `مقدماتی` |
| | متوسط | `متوسط` |
| | پیشرفته | `پیشرفته` |

- **راهنمای جامع** فقط برای مطالب واقعاً جامع (مثل آموزش ۶۶ دقیقه‌ای آپشن). اگر
  همه‌چیز «جامع» باشد، هیچ‌چیز نیست — پیشنهاد: حداکثر ۳ تا ۵ مطلب.
- **شروع از صفر** برای مطالبی که خواننده‌ی تازه‌کار باید اول بخواند.
- **سطح** روی هر مطلب حداکثر یکی.

## ۲. مقاله‌ی آپشن — پیشنهاد تیم

مطلب «آموزش آپشن به زبان ساده» (۶۶ دقیقه) [ویرایش](https://wp.thefinance.ir/wp-admin/post.php?post=2724&action=edit):

- برچسب‌های `راهنمای-جامع`، `آپشن` و یک سطح بزنید.
- پیشنهاد تیم برای عنوان: **«راهنمای جامع اختیار معامله؛ از صفر تا شناخت Call، Put و استراتژی‌های آپشن»**

⚠️ **نامک (آدرس) مطلب را تغییر ندهید** — فقط عنوان. تغییر نامک آدرسی را که در
گوگل رتبه دارد می‌شکند.

## ۳. توضیح زیر عنوان کارت‌ها از کجا می‌آید

از امروز توضیح کوتاه زیر عنوان هر کارت، **همان «توضیحات» Rank Math** هر مطلب
است (همان که در نتایج گوگل دیده می‌شود). قبلاً از تیترهای H2 مقاله ساخته
می‌شد که شبیه فهرست مطالب بود.

۴۶ مطلب از ۵۶ مطلب آموزشی توضیح نوشته‌شده دارند. **۱۰ مطلب زیر توضیح ندارند و
Rank Math خودش اولین پاراگراف مقاله را جایش گذاشته** — که روی کارت مثل متن
بریده‌شده خوانده می‌شود. برای این‌ها یک جمله‌ی واقعی بنویسید، مثل نمونه‌ی تیم:
«با مفهوم عیار طلا، تفاوت ۱۸ و ۲۴ عیار و اعداد ۷۵۰ و ۹۹۹ آشنا شوید.»
